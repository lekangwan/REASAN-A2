# REASAN-A2 导航权重交接

给接手同学在自己的 A2 仿真场景里评估。主文件是 **`models/nav_a2_finetune_iter500.pt`**，它是从官方 Go2 导航权重开始、在 A2 上微调 500 次 PPO 后导出的 TorchScript 导航 actor。

## 开始使用

解压后先进入压缩包的根目录，在现有的 PyTorch 环境中运行：

```bash
sha256sum -c SHA256SUMS
python3 check_inference.py
```

已用评测容器内的 PyTorch 2.5.1 在 CPU 上检查过三个模型的加载、连续推理和回合复位。脚本里的两个输入是接口检查样例。使用自己的场景时，按下面的定义用实际观测替换样例输入。

| 文件 | 用途 |
| --- | --- |
| `models/nav_a2_finetune_iter500.pt` | 需要接入的导航权重 |
| `models/filter_official.pt` | 取得参考成绩时固定使用的 REASAN 官方安全层 |
| `models/a2_moe_student_103500.pt` | 取得参考成绩时固定使用的 A2 MoE 学生模型 |
| `contracts/ROBOT_CONTRACT.json` | A2 的关节名称、顺序、观测归一化和 PD 参数 |
| `contracts/STUDENT_POLICY.json` | A2 学生模型的来源及历史输入说明 |
| `reports/maze80_finetune500_comparison.json` | 80 条本地迷宫逐条结果和原导航对照 |
| `reports/maze80_finetune500_summary.json` | 本地评测的权重来源和物理设置 |

本地测试链路每 20 毫秒更新一次：导航 actor → 官方安全层 → A2 MoE。仿真物理步长为 5 毫秒。使用自己的安全层、底层控制策略或射线时，请在成绩里注明实际配置。

## 导航输入与输出

`nav(proprio, rays)` 接收两个 `float32` 张量，形状分别为 `[N, 11]`、`[N, 180]`。返回 `[N, 3]`，依次为机体坐标系的 `vx`、`vy` 和 `wz`，单位分别为米/秒、米/秒和弧度/秒。

11 维 `proprio` 按以下顺序拼接。

1. 机体坐标系的基座质心角速度三维，乘以 `0.25`。
2. 机体坐标系的投影重力三维。水平站立时约为 `[0, 0, -1]`。
3. 用机身偏航将世界坐标系的目标相对位移旋到机体水平坐标系，取 `x, y` 两维，单位为米。参考代码保留距离原值。
4. 上一控制周期导航 actor 的原始三维输出。回合开始时填零。

评测入口沿用上游观测函数，在导航输入的缩放后角速度和投影重力上，分别加入幅值为 0.20 和 0.05 的均匀噪声。安全层读取的是同一周期的无噪声角速度和重力。

180 维 `rays` 为机体水平角从 `-180°` 到 `178°`、每 `2°` 一项的归一化距离。参考评测使用上游 `11x` 仿真射线：每个方向汇总 11 个机身平面起点、每个起点 3 个高度。对每个方向，取命中点到基座位置的最小三维欧氏距离，截到 3 米后除以 3。该方向没有命中时填 `1.0`。跑自有场景时，建议先复用上游 `ray_3d_3x180_parallel_11x_pattern`，这样射线角度和起点一致。

两个 TorchScript 网络内部都有 LSTM 状态，权重默认按单环境导出。并行时，在首次推理前将各自的 `h_state`、`c_state` 调整为 `[层数, N, 隐维]`。每个回合复位时，清零相应环境的两个状态及历史动作。示例脚本演示单环境用法。

## 安全层和步态

安全层接收同一组 180 维射线，以及 12 维输入。后者由缩放后的机体角速度、投影重力、当前导航原始输出、上次安全层原始输出各三维组成。将安全层新输出按 `[2.5, 1.5, 3.0]` 的绝对值上限限幅，再给 A2 步态控制。

A2 学生模型的输入是 `[N, 45]` 当前观测和 `[N, 5, 45]` 历史，输出 12 维关节动作和更新后的历史。需要完整的观测到动作、关节顺序和显式 PD 实现时，参考交接仓库的 `a2_adapter/low_level.py` 和 `docs/HANDOFF.md`。 [REASAN-A2 基础交接仓库](https://github.com/lekangwan/REASAN-A2)

## 我们这边的参考成绩

| 导航 | 到达 | 碰撞 | 超时 |
| --- | ---: | ---: | ---: |
| 原导航直迁 A2 | 47/80（58.75%） | 8 | 25 |
| **微调第 500 次** | **53/80（66.25%）** | **6** | **21** |
| 从头训练第 750 次 | 32/80（40.00%） | 15 | 33 |
| 从头训练续训第 1250 次 | 39/80（48.75%） | 10 | 31 |

这组结果来自我们固定的八张静态迷宫，每张十组初态。水平距离小于 0.5 米为到达，每条限时 30 秒。同一步触发碰撞或倾斜时优先判失败。请把自己场景的地图、到达条件、时限、到达及失败次数随结果一起记录。
